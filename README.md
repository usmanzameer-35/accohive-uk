# AccoHive UK

Standalone UK website for AccoHive, focused on white-label accounting, finance operations and back-office support for UK accountancy practices.

## Local preview

Serve the repository root with any static file server, for example `npx serve .`.

## Deployment

Import `usmanzameer-35/accohive-uk` into Vercel as a static site. No build command or output directory is required.
